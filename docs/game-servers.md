# Game server roadmap

Game server management is Phase 3 and will use adapters. The core lifecycle will cover
install, configure, start, stop, restart, console/logs, resource limits, ports,
backups, schedules, crash recovery, and verified updates.

Initial adapters are planned for Minecraft Java/Bedrock, Terraria, Valheim, and CS2.
Pterodactyl and Docker remain optional integrations and cannot become prerequisites
for core NexaGrid operation. No game-server functionality ships in v0.1.
