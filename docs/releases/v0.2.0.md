# Veltrix-Control v0.2.0 — Native control center

Veltrix-Control is now app-first. The installer places a native, resizable Windows control
center on the Controller computer and all primary administration happens there. The local
web surface remains available only as a recovery option if the app cannot start.

## Highlights

- Native setup, sign-in, fleet overview, devices, diagnostics, files, audit, and settings.
- Live CPU, memory, health, online state, inventory, disk, uptime, and heartbeat details.
- Device search, status filters, sorting, copyable identity, and role-aware controls.
- Remote read-only lists for processes, services, installed software, and network adapters.
- Managed-root file navigation and guarded restart/shutdown requests.
- Enrollment code creation, automatic copy, lifetime selection, rotation, and revocation.
- Audit search, hash-chain integrity verification, and CSV export.
- System light/dark adaptation, semantic color tokens, keyboard shortcuts, and clear states.
- App-first launcher with a failure-only browser fallback prompt.
- Self-contained Windows x64 build; no separate .NET installation is required.

## Install

Download `Veltrix-Control-Setup.exe`, verify it against `SHA256SUMS.txt`, run it as
administrator, and select Controller, Managed Node, or both. A Controller installation
adds the **Veltrix-Control** app shortcut.

Power actions remain disabled on real managed nodes unless an administrator explicitly
enables the local Agent policy. The installer is not Authenticode-signed because no
publisher certificate has been supplied, so Windows may show an unknown-publisher warning.
