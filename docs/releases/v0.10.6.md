# Veltrix-Control v0.10.6 — Carbon interface and installer theme

## Highlights

- **The delivered Carbon UI kit is implemented in the native app.** Graphite surfaces, a
  mint accent, fine borders, and flat backgrounds replace the previous gradient shell. No
  HTML or WebView is used; the design was ported to WPF so all existing functionality,
  permissions, confirmations, and audits remain native.
- **New shell layout:** 210 px navigation with the VELTRIX monogram and wordmark, workspace
  card, breadcrumb, global device search with a `Ctrl F` hint, controller status pill,
  account card with initials, and a status bar showing the real Controller address, online
  count, and TLS state.
- **Tables and metrics:** status dots with labels, health bars with `N / 100`, and memory
  shown as `used / total` with free RAM. Primary actions are flat mint with dark text.
- **Installer theme:** the Inno Setup wizard now uses graphite pages, mint page names and
  Next button, and role selection cards with a mint selection edge. Service registration,
  firewall rules, repair, upgrade, and uninstall behavior are unchanged.

## What this is not

The kit is a visual handoff, not a working application. Its sample data, simulated install
progress, animated topology, and demo diagnostics are not used. Anything that could not be
ported faithfully — browser-persisted appearance toggles, the animated fleet topology
graph, original outline icons, and owner-drawn installer buttons — is listed in the
not-implemented report.
