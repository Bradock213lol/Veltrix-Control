# Veltrix-Control v0.10.2 — Recovery account, clean uninstall, themed windows

## Highlights

- **Recovery Administrator account** — after first-run setup the Controller automatically
  creates a second account so a forgotten Owner password can never lock you out:
  - Username: `admin`
  - Password: `admin!`
  It is created only when missing (it never overwrites a changed password), is
  configurable under `Controller:RecoveryAccount*`, and the Controller logs a warning when
  it is created. Change its password or delete the account in **Settings → User accounts**
  once Owner access is verified.
- **Clean uninstall** — uninstalling through Windows Settings now removes everything the
  product created: services, firewall rule, program files, the database with user
  accounts, certificates, node identities, transfers, transfers metadata, and desktop
  settings. Silent uninstall (used during upgrades and repair) preserves data so fleet
  state survives.
- **Themed windows** — every window now uses the application theme background. The large
  white area around the sign-in card and other content is gone.

## Upgrade notes

- Install over the previous release; existing data and accounts are preserved.
- The recovery account is added automatically on the first Controller start after the
  upgrade (or immediately after first-run setup on a new install).

## Verification

- Release build with zero warnings: **PASS**.
- Automated suites, including a new test that signs in with the recovery account after
  setup and verifies its Administrator role, pass on Windows CI before publication.
