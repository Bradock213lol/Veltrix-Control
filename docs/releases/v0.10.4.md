# Veltrix-Control v0.10.4 — Telemetry clarity and design-system polish

## Highlights

- **Memory reads used / total with free capacity everywhere** — Overview shows
  `6.3 GB / 32 GB` with `25.7 GB free across online nodes`; the device directory adds
  Memory used / total and Free RAM columns; the device profile shows both plus a
  percentage detail.
- **Tabular metric figures** keep numbers aligned and stable while they update, giving the
  dashboard an instrument-panel feel instead of shifting text.
- **Device profile redesign** — metric cards with captions (health band, processor count,
  memory detail, uptime) and a storage table with used / total, free, and used percent.
- **Role-aware navigation** — sections the signed-in role cannot use are disabled with a
  tooltip that explains why, instead of failing later.
- **Clear action hierarchy** — one primary action per toolbar.
- **Motion with respect** — a short content fade on navigation and a pulsing refresh
  indicator, both disabled automatically when Windows animations are off.
- **Self-explaining empty states** for the Overview, Devices, Files, Alerts, and Audit
  grids, plus contrast improvements to secondary text.

## Fixed

- Health displays as `82/100` and offline devices say "Offline" rather than showing a
  bare zero.

- Release build with zero warnings: **PASS**.
