# NexaGrid v0.1.0 - Phase 1 Preview

This is the first independently installable NexaGrid milestone: a secure Windows fleet
foundation for explicitly authorized computers. It is published as a preview while the
project gathers real-environment feedback and obtains an Authenticode signing certificate.

## Download

- `NexaGridSetup.exe` - single Windows x64 installer with Controller, Managed Node, and
  combined role selection.
- `SHA256SUMS.txt` - SHA-256 checksums for verifying the downloaded files.
- `NexaGrid-Windows-x64.zip` - installer, checksum manifest, version, and changelog bundle.

## Included

- First-run Owner setup, secure sessions, four roles, and permission enforcement.
- Expiring single-use enrollment codes and persistent ECDSA P-256 node identities.
- Certificate-pinned HTTPS, signed heartbeats, replay protection, and reconnect behavior.
- Live CPU, RAM, disk, uptime, hardware inventory, health, and online/offline state.
- Guarded restart/shutdown operations with Agent-side opt-in.
- Read-only remote browsing constrained to an administrator-selected filesystem root.
- Hash-chained audit history and a clearly labelled multi-node simulator.
- Self-contained Controller, Agent, and Simulator binaries; no separate .NET runtime needed.

## Release verification

- Release build: zero warnings and zero errors.

## Install

1. Download `NexaGridSetup.exe` and `SHA256SUMS.txt` from the release assets.
2. Verify the checksum in PowerShell:

   ```powershell
   (Get-FileHash .\NexaGridSetup.exe -Algorithm SHA256).Hash
   ```

3. Run the installer as administrator and choose Controller, Managed Node, or both.
4. For a Controller, open `http://localhost:5187`, create the Owner, and generate an
   enrollment code for each remote node.
5. Verify the Controller certificate fingerprint out of band before enrolling another PC.

Read `docs/installer.md` and `docs/security.md` before exposing a Controller beyond the
local host.

## Known limitations

- The installer is not Authenticode-signed. Windows may show an unknown-publisher warning;
  verify the SHA-256 manifest before running it.
- The Controller uses a locally generated self-signed certificate for node transport.
- Phase 1 file access is read-only. Transfers, editing, and file mutations are Phase 3.
- Power actions are disabled on real Agents until an administrator opts in locally.
- SQLite supports the current single-Controller deployment, not high availability.

Use NexaGrid only on computers you own or are explicitly authorized to administer.
