# Veltrix-Control v0.3.0 — Managed files, transfers, and editing

Veltrix-Control v0.3.0 makes the managed root fully maintainable from the desktop control
center while keeping every path decision enforceable on the managed node.

## Highlights

- Create, rename, move, copy, and delete files and folders inside the configured managed
  root. Every mutation is authorized by `device.files`, validated again on the node, and
  recorded in the audit history.
- Wildcard file search and bounded folder sizing.
- ZIP creation and extraction with entry-count, size, and zip-slip protection.
- Chunked uploads and downloads with progress, cancellation, sequential offsets, and
  SHA-256 verification before a transfer is reported complete.
- Built-in text editor with line numbers, find/replace, atomic saves, automatic pre-save
  backups, per-file history with restore, and a line-level comparison against any backup.
- Hardened path policy covering traversal, absolute paths, UNC/device paths, alternate
  data streams, null bytes, reparse-point escapes, and archive entry escapes.

## Upgrade and compatibility

- One `Veltrix-Control-Setup.exe` still installs the Controller, Managed Node, or both.
- The database schema is extended automatically; existing Controller and node data are
  preserved across repair and upgrade.
- Existing v0.2 operations, enrollment, telemetry, and audit history remain unchanged.

## Verification

- Release build with zero warnings: **PASS**.
- Automated suites: unit, security, Agent, integration, and Controller-to-Agent
  end-to-end, including new file-engine, path-escape, and transfer workflow tests.
- Transfers complete only after checksum verification, and cancelled or failed transfers
  are never reported as complete.

## Known limitations

- Binaries are not Authenticode-signed; Windows may show an unknown-publisher warning.
- Transfers resume from the last sequential offset; arbitrary range requests are not
  supported.
- The editor is optimized for text and configuration files up to 2 MB; binary editing is
  intentionally unsupported.
