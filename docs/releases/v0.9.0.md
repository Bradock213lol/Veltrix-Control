# Veltrix-Control v0.9.0 — Optional Pterodactyl and Docker integrations

Veltrix-Control v0.9.0 can observe and control existing Pterodactyl and Docker
environments without making them dependencies of core management workflows.

## Highlights

- **Pterodactyl** — health checks, node and server listings, and confirmed start, stop, and
  restart actions through the official application API.
- **Docker** — engine health, containers, images, volumes, lifecycle actions, and bounded
  container logs over npipe or HTTPS endpoints.
- **Credential safety** — AES-GCM encryption at rest with a Controller-local key;
  credentials never appear in API responses and are removed with the integration.
- **Isolation** — a dedicated module and adapter contract keep integration outages from
  affecting enrollment, telemetry, files, backups, or game servers.
- **Desktop workspace** — a dedicated Integrations surface with health, resources,
  actions, logs, and deletion.

## Verification

- Release build with zero warnings: **PASS**.
- Automated suites pass, including credential, validation, health, permission, and
  confirmation coverage.

## Known limitations

- Pterodactyl console logs require the client API and websocket access.
- Docker plaintext TCP endpoints are limited to loopback.
- Binaries are not Authenticode-signed; Windows may show an unknown-publisher warning.
- Production hardening is the remaining milestone.
