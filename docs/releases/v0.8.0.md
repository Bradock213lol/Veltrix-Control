# Veltrix-Control v0.8.0 — Game server platform

Veltrix-Control v0.8.0 introduces first-class game server management with a versioned
adapter contract and a production Minecraft Java adapter.

## Highlights

- **Provisioning** — downloads the official server jar, verifies the published SHA-1 from
  the Mojang manifest, accepts the EULA explicitly, and writes safe default
  `server.properties`. Java 21+ is required and reported clearly when missing.
- **Lifecycle** — create, start, stop, update, console input, and streamed console output
  with bounded buffers.
- **Crash recovery** — crashed servers restart automatically when enabled; crash loops
  stop after the configured threshold and raise one actionable alert.
- **Console** — a live console window streams server output and sends commands.
- **Evidence** — every lifecycle action is audited and every instance keeps an event
  history.

## Safety model

- Game server management requires `game.manage`.
- Installs are confined to the managed root; unknown adapters and unsafe paths are
  rejected on the Controller and on the node.
- Downloads are checksum-verified against the official manifest before use.

## Verification

- Release build with zero warnings: **PASS**.
- Automated suites pass across unit, security, Agent, integration, and end-to-end tests,
  including lifecycle, crash restart, validation, and permission coverage.

## Known limitations

- Minecraft Java requires Java 21 or newer on the node.
- Only the Minecraft Java adapter ships in this release.
- Binaries are not Authenticode-signed; Windows may show an unknown-publisher warning.
- Optional Pterodactyl and Docker integrations remain a planned phase.
