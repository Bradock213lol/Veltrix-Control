# Veltrix-Control v0.10.8 — Tags, favorites, webhook alerts, Chocolatey

## Added

- **Device tags and favorites** — tag devices for grouping (Production, Testing, Site A),
  star important ones, search by tag, and see tags in the directory. Tag changes require an
  Administrator and are audited; favorites are per-controller and available to every role.
- **Alert notifications** — deliver alert events to an HTTPS webhook with an
  `X-Veltrix-Signature: sha256=...` HMAC header when a secret is set. Settings provide
  Save and Send test; the secret is encrypted at rest with the Controller-local key.
- **Chocolatey packages** — install, uninstall, and upgrade through Chocolatey wherever it
  is installed on the node, selectable next to WinGet, MSI, and EXE.

## Verification
