# Veltrix-Control v0.10.0 — Production hardening (partial)

Veltrix-Control v0.10.0 completes the hardening work that could be implemented and
verified: user administration, automatic retention, agent-version policy, and system
diagnostics.

## Highlights

- **User administration** — create, list, change roles, reset passwords, and delete
  accounts. The last Owner cannot be demoted or deleted, and every change is audited.
- **Automatic retention** — finished operations, compute jobs, automation runs, terminal
  history, update scans, game server events, resolved alerts, and metrics are purged on a
  schedule. Audit events are deliberately never deleted because that would break the
  tamper-evident hash chain.
- **Agent-version policy** — nodes on a different version than the Controller raise an
  informational alert that clears after upgrade.
- **System diagnostics** — administrators can read version, uptime, device counts, open
  alerts, queued operations, and retention settings.

## Honest status

This is **not** a full GA release. PostgreSQL, signed self-update with staged rollout,
enterprise identity, high availability, and load/soak qualification are not implemented
and are documented as remaining in `PHASES.md` and `RESULT.md`.

## Verification

- Release build with zero warnings: **PASS**.
- Automated suites: 138 tests pass across unit, security, Agent, integration, and
  end-to-end coverage.

## Known limitations

- SQLite-only persistence.
- Manual agent upgrades.
- Local authentication only.
- No HA or 1,000-node qualification.
- Binaries are not Authenticode-signed.
