# Veltrix-Control v0.10.5 — Interface signature, shortcuts, and honest roadmap

## Highlights

- **Added a signature visual layer** in an instrument-console direction: a soft aurora glow
  behind the workspace, a violet gradient accent and primary buttons, a gradient brand
  mark, larger panel radii, and thin utilization bars beneath the Overview metrics so each
  number reads with its proportion.
- **Keyboard shortcuts are documented in the app** under **Settings ? Keyboard shortcuts**
  and in the README; new accelerators: `Ctrl+1 … Ctrl+9` for the nine sections,
  `Ctrl+R` to refresh, and `Ctrl+S` / `Ctrl+F` in the file editor.
- **Repository documentation rewritten** for a company audience: a feature-status table, a
  shortcut reference, an accurate architecture and security summary, and an explicit list
  of what is not implemented, backed by `docs/roadmap.md`.
- **Honesty fixes:** the README no longer implies features that ship as desktop-only, and
  the browser fallback is documented as a recovery surface frozen at the v0.2 feature set.

## Verification

- Release build with zero warnings: **PASS**.
- 156 automated tests pass on Windows CI; the desktop app was smoke-launched to confirm the
  new visual layer loads without errors.
