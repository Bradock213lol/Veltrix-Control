# Veltrix-Control v0.10.1 — First-run setup and account recovery

Veltrix-Control v0.10.1 fixes first-time installation so creating the Owner credentials is
always possible, adds a safe password-recovery path, and gives the Overview tab a
getting-started checklist.

## Fixes

- **Reliable first-run detection** — the desktop app now waits for the Controller service
  to finish starting, then shows a dedicated "Create your control plane" form with a
  password confirmation field and password guidance whenever the Controller has no
  accounts.
- **Automatic setup fallback** — if a sign-in attempt finds that no accounts exist, the app
  switches to setup mode with a clear explanation instead of a generic error.
- **Specific validation messages** — the Controller now says "Enter your username." or
  "Enter your password." instead of "Login request is invalid."
- **Owner password recovery** — on the Controller machine, an elevated prompt can reset a
  password without deleting data:

  ```powershell
  $env:VELTRIX_OWNER_PASSWORD = 'a-new-owner-password'
  & "$env:ProgramFiles\Veltrix-Control\Controller\Veltrix-Control.Controller.exe" --reset-owner owner-username
  Remove-Item Env:\VELTRIX_OWNER_PASSWORD
  ```

  The reset is recorded in the audit history.

## Added

- Getting-started checklist on the Overview tab that guides the first enrollment:
  create a code, install the Managed Node role, enroll, and review the audit trail.

## Upgrade notes

- Install over the previous release; all existing data, accounts, and node identities are
  preserved.
- If the previous installation already has accounts, the app shows sign-in as before and
  the recovery command is available if the password was lost.
