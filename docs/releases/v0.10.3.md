# Veltrix-Control v0.10.3 — Enterprise UI polish

## Highlights

- **Original control templates** replace the default WPF chrome that made the app look
  inconsistent: buttons now have proper hover, pressed, and disabled states; text and
  password fields have hover and accent focus rings; combo boxes open themed drop-downs;
  checkboxes, tabs, data grids, scrollbars, list boxes, progress bars, tooltips, and focus
  visuals all match the product theme in both light and dark modes.
- **Themed window chrome** — title bars match the active theme on Windows 10 and 11
  instead of staying bright white.
- **Navigation** — icon navigation with clear active-state highlighting, a link style for
  secondary actions, and the product version shown in the sidebar.
- **Consistent layout** — typography, spacing, labels, grid rows, and empty states were
  normalized across every screen.

## Fixed

- The Windows Update "Install" checkbox column is editable again; the grid was read-only
  and ignored the selection.

## Upgrade notes

- Install over the previous release; no configuration or data changes are required.

## Verification

- Release build with zero warnings: **PASS**.
- Automated suites pass on Windows CI, and the desktop app was smoke-launched to confirm
  the new theme loads without resource errors.
